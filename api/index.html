API Reference

This reference covers every public type in yak2D. It is generated from the comments in the source code every time yak2D is released, so it always matches the current NuGet package.

Where to start

Almost everything is reached through a few entry points:

Type What it is
Launcher Starts yak2D: Launcher.Run(new MyGame()).
IApplication The interface your game implements.
StartupConfig Window, graphics and timing settings, returned from Configure().
IServices Every yak2D service, passed to most IApplication methods as yak.
IDrawing Submitting draw requests and text, in Drawing().
IDrawingHelpers Quads, polygons, lines, arrows and the fluent shape builder (draw.Helpers).
IRenderQueue Building the frame's rendering, in Rendering().

The services

Service Access For
ISurfaces yak.Surfaces textures and render targets
IStages yak.Stages render stages, their configuration, and viewports
ICameras yak.Cameras 2D and 3D cameras
IFonts yak.Fonts loading fonts, measuring text
IInput yak.Input keyboard, mouse and gamepads
IDisplay yak.Display the window
IBackend yak.Backend the graphics API
IFps yak.FPS update and draw rates
IHelpers yak.Helpers coordinate transforms, mesh builders, distortion helpers

Most methods that take a reference (such as an ITexture) also have an overload taking the raw ulong id instead. See Resources and references.

For explanations and examples, see the Manual.
