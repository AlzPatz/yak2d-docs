Interface IDistortionCollection

Namespace
Yak2D
Assembly
Yak2D.Api.dll

A collection used to manage the evolution, position, size, intensity of distortion 'sprites' (textured square quads) over time The user should call Update() and Draw() to evolve and display the collection

Parameters

cycle LifeCycle

The distortion object can be looped

The coordinate space (world or screen) that the distortion object should be drawn in

The length of a single cycle

texture ITexture

The texture reference

initPosition Vector2

Location the textured quad is positioned at the start of a cycle

finalPosition Vector2

The textured quad's final position, position is interpolated from init to final over the cycle

initSize Vector2

Quad (square) dimensions at the start of a cycle

finalSize Vector2

Quad (square) dimensions at the end of a cycle, the size is interpolated over the cycle

initIntensity float

Drawn intensity of texture at the start of a cycle

finalIntensity float

Drawn intensity of texture at the end of a cycle, the intensity is interpolated over the cycle

initialRotation float

Rotation in degress at the start of a cycle

finalRotation float

Rotation in degress at the end of a cycle, angle is interpolated during a cycle
