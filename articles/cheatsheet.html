A complete application

Every yak2D program is one class implementing IApplication, passed to Launcher.Run(). This is a complete program, a good starting point to copy:

using System.Numerics;
using Yak2D;

Launcher.Run(new Hello());

public class Hello : IApplication
{
    private IDrawStage _stage;
    private ICamera2D _camera;

    public StartupConfig Configure() => StartupConfig.Default(960, 540, "Hello, yak2D", false);

    public void OnStartup() { }

    public bool CreateResources(IServices yak)
    {
        _stage = yak.Stages.CreateDrawStage();
        _camera = yak.Cameras.CreateCamera2D(960, 540);
        return true;
    }

    public void ProcessMessage(FrameworkMessage msg, IServices yak)
    {
        if (msg == FrameworkMessage.GraphicsDeviceRecreated) CreateResources(yak);
    }

    public bool Update(IServices yak, float seconds) => !yak.Input.WasKeyPressedThisFrame(KeyCode.Escape);

    public void PreDrawing(IServices yak, float secondsSinceLastDraw, float secondsSinceLastUpdate) { }

    public void Drawing(IDrawing draw, IFps fps, IInput input, ICoordinateTransforms transforms,
                        float secondsSinceLastDraw, float secondsSinceLastUpdate)
    {
        draw.Helpers.DrawColouredPoly(_stage, CoordinateSpace.Screen, Colour.Gold, Vector2.Zero, 5, 120.0f, 0.5f);
        draw.DrawString(_stage, CoordinateSpace.Screen, "Hello, yak2D", Colour.White, 48.0f,
                        new Vector2(0.0f, -150.0f), TextJustify.Centre, 0.5f, 0);
    }

    public void Rendering(IRenderQueue q, IRenderTarget window)
    {
        q.ClearColour(window, Colour.DarkSlateBlue);
        q.ClearDepth(window);
        q.Draw(_stage, _camera, window);
    }

    public void Shutdown() { }
}

When each method runs

Method Runs Put here Gets
Configure() once, first window size, title, timing (StartupConfig)
OnStartup() once your own (non-yak2D) objects
CreateResources() once, then by you after a device reset textures, stages, cameras, fonts, render targets yak
ProcessMessage() per message, before Update() device reset, focus, resize, gamepads yak
Update() every step (120 per second by default) input, movement, game rules. return false quits yak, step length
PreDrawing() every frame camera moves, effect settings yak
Drawing() every frame draw.… calls: what to draw draw, fps, input, transforms
Rendering() every frame q.… calls: how to render it q, the window
Shutdown() once, last save settings, release your own things

Drawing (in Drawing())

All drawing goes to a draw stage and takes a coordinate space, a depth and (usually) a layer.

Draw Call
Rectangle draw.Helpers.DrawColouredQuad(stage, space, colour, centre, width, height, depth)
Sprite draw.Helpers.DrawTexturedQuad(stage, space, texture, tint, centre, width, height, depth)
Part of a texture (sprite sheet) …DrawTexturedQuad(…, texcoord_min_x: …, texcoord_max_x: …) (recipe)
Polygon or circle draw.Helpers.DrawColouredPoly(stage, space, colour, centre, sides, radius, depth)
Line, arrow draw.Helpers.DrawLine(stage, space, from, to, width, colour, depth), DrawArrow(…)
Text draw.DrawString(stage, space, text, colour, size, topPosition, TextJustify.Centre, depth, layer) (Text)
Outlines and more shapes draw.Helpers.Construct().Coloured(c).Poly(…).Outline(w).SubmitDraw(stage, space, depth, layer) (fluent builder)
Your own triangles draw.Draw(stage, new DrawRequest { … }) (draw requests)

Ordering: higher layer is always on top. Within a layer, lower depth (0 to 1) is nearer. Positions are the centre of a shape, except text, where y is the top. Angles are radians, clockwise.

Rendering (in Rendering())

The render queue runs in the order you build it. A render target can be the output of one step and the input of the next.

q.ClearColour(target, Colour.Black);       // start each target you render to
q.ClearDepth(target);
q.Draw(drawStage, camera, target);         // draw stage → target, through a 2D camera
q.Bloom(bloom, source, target);            // effects: read a texture, write a target
q.Blur(blur, source, target);              //   also Blur1D, ColourEffects, StyleEffects
q.Distortion(distortion, camera, source, target);
q.Mix(mix, mask, tex0, tex1, tex2, tex3, target);
q.MeshRender(mesh, camera3D, source, target);
q.CustomShader(shader, tex0, tex1, tex2, tex3, target);
q.Copy(source, target);                    // stretch any surface onto a target
q.SetViewport(viewport);                   // render into part of a target...
q.RemoveViewport();                        // ...then the whole target again

Details: The render queue and render stages, Post-processing effects.

Coordinate spaces

Space Origin +Y Units Used for
World world (0,0), wherever the camera looks up world units the game world: moves, zooms and rotates with the camera
Screen centre of the camera's view up virtual resolution (e.g. 960 x 540) HUDs and menus: fixed to the view
Window top-left of the window down real pixels mouse position, viewports

Convert with transforms (in Drawing()) or yak.Helpers.CoordinateTransforms: WorldFromWindow(input.MousePosition, camera) and friends. Details: Coordinate systems.

Blend states

Set per draw stage: yak.Stages.CreateDrawStage(true, BlendState.AdditiveAlpha).

BlendState Use for
Alpha (default) almost everything
AdditiveAlpha light, fire, sparks, glows
AdditiveComponentWise accumulating values
Override replacing pixels outright
Premultiplied drawing a transparent render target over something else (1.2.0+)

Remember

  • Create every yak2D resource in CreateResources(), and call it again on FrameworkMessage.GraphicsDeviceRecreated. (Device resets)
  • Draw stages are emptied every frame by default: submit everything you want to see, every frame. (Drawing things once)
  • Keep a camera's virtual resolution the same shape as what it renders to, or the picture stretches. (Cameras)
  • Nothing on screen? See Troubleshooting.
